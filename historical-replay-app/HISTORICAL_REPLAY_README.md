# Isolated real-data replay

This folder is a standalone copy of the QUAY application. The original `src`
folder is not modified by this experiment.

The historical workflow uses official NOAA Marine Cadastre AIS files supplied by
the downloader or by you. It does not ship invented AIS observations. Begin with
the exact platform-specific commands, field lineage and limitations in
[docs/historical-replay.md](docs/historical-replay.md).
